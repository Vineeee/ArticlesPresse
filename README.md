# Mon Projet Java

## Description
Description de votre projet Java.

## Prérequis
- Java 11 ou supérieur
- JDK installé et configuré dans PATH

## Structure du projet
```
JavaV2/
├── src/
│   ├── main/
│   │   ├── java/
│   │   │   └── com/example/app/
│   │   └── resources/
│   └── test/
│       └── java/
│           └── com/example/app/
├── lib/                    # Dépendances externes
├── bin/                    # Fichiers compilés
├── docs/                   # Documentation
├── compile.bat            # Script de compilation
├── run.bat               # Script d'exécution
└── README.md
```

## Compilation
```cmd
compile.bat
```

## Exécution
```cmd
run.bat
```

## Tests
```cmd
test.bat
```
